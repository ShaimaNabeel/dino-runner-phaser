# Dino Runner Game

A browser-based endless runner game developed with Phaser.js.

The player controls a dinosaur, avoids obstacles, collects points, and reaches a game-over state after a collision.

## Gameplay

![Dino Runner Game](images/dino-gameplay.png)

## Features

- Player movement controls
- Obstacle generation
- Collision detection
- Score tracking
- Game-over state
- Browser-based gameplay

## Tech Stack

- JavaScript
- Phaser.js
- HTML
- CSS

## Project Files

- HTML files — Game page structure
- JavaScript files — Game logic and Phaser.js implementation
- CSS files — Game styling
- Assets — Game sprites and visual elements
